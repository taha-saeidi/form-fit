# راهنمای انتشار روی Cloudflare (مرحله اول)

پیش‌نیاز: Node.js نسخه ۲۴ (`node -v` باید `v24...` نشان بدهد)، حساب Cloudflare، و VPN فعال برای ورود به Cloudflare.

همه دستورها را داخل پوشه‌ی پروژه اجرا کن.

## ۱) نصب وابستگی‌ها
```
npm ci
```

## ۲) ورود به Cloudflare
```
npx wrangler login
```
مرورگر باز می‌شود؛ اجازه را تأیید کن.

## ۳) ساخت دیتابیس
```
npx wrangler d1 create formfit
```
خروجی یک `database_id` دارد (چیزی شبیه `xxxxxxxx-xxxx-...`). آن را در `wrangler.jsonc` جای مقدار `00000000-0000-4000-8000-000000000000` بگذار.

## ۴) ساخت پروژه
```
npm run build
```
هر بار که `wrangler.jsonc` را تغییر دادی، قبل از دیپلوی دوباره `npm run build` بزن؛ دیپلوی تنظیمات را از خروجی همین مرحله می‌خواند.

## ۵) ساخت جدول‌ها روی دیتابیس واقعی
```
npm run db:remote
```

## ۶) دیپلوی اول
```
npm run deploy
```
آخر خروجی یک آدرس مثل `https://formfit.<نام-تو>.workers.dev` چاپ می‌شود. آن را کپی کن.

## ۷) تنظیم APP_ORIGIN (حیاتی)
در `wrangler.jsonc` مقدار `APP_ORIGIN` را دقیقاً برابر همان آدرس بگذار (با `https://` و بدون `/` آخر). بعد:
```
npm run build
npm run deploy
```
اگر این مقدار با آدرسی که در مرورگر باز می‌کنی یکی نباشد، ورود و ثبت‌نام و ثبت حرکت با خطای «درخواست نامعتبر» رد می‌شوند.

## ۸) ساخت ادمین
در سایت ثبت‌نام کن (رمز حداقل ۱۲ کاراکتر)، بعد:
```
node scripts/admin.mjs ایمیل-خودت@example.com --remote
```
بعد از آن، صفحه `/admin` برای تو باز می‌شود.

## ۹) بررسی خطاها
```
npm run logs
```
هنگام ثبت‌نام و ورود نگاه کن. اگر خطای مربوط به CPU (مثل `Exceeded CPU` یا کد 1102) دیدی، هش رمز روی پلن رایگان سنگین است و باید پلن Workers Paid بگیری.

## بعداً: دامنه‌ی foarmfit.ir
Workers برای دامنه‌ی اختصاصی لازم دارد دامنه در Cloudflare اضافه شود. در داشبورد Cloudflare «Add a site» را با `foarmfit.ir` امتحان کن؛ اگر `.ir` را قبول نکرد، همان آدرس `workers.dev` را نگه دار تا سرور ایران آماده شود. پس از هر تغییر دامنه، `APP_ORIGIN` را هم عوض و دوباره build و deploy کن.

## ورود با گوگل
فعلاً غیرفعال است و مشکلی ایجاد نمی‌کند؛ ورود با ایمیل کار می‌کند.
